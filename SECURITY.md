# Security policy

## Supported versions

Only the latest published version of each package receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting instead:
<https://github.com/shout-out/emoji-mart/security/advisories/new>

You will get an acknowledgement within a few days. Once a fix is ready we will
publish a patch release and credit you in the advisory unless you prefer
otherwise.
